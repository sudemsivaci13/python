# Dimensionality Reduction with Principal Component Analysis (PCA)

This project demonstrates an unsupervised machine learning workflow using Principal Component Analysis (PCA) to reduce high-dimensional data into a lower-dimensional space while preserving maximum variance.

It covers the full dimensionality reduction lifecycle on the Iris dataset—from initial data visualization (pairplots) and feature standardization with StandardScaler to component variance evaluation via Scree plots. Finally, the dataset is projected onto 2 principal components to visualize linear separability and compress feature dimensions with minimal information loss.
