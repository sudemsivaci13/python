# Supervised Dimensionality Reduction with Linear Discriminant Analysis (LDA)

This project demonstrates a supervised machine learning workflow using Linear Discriminant Analysis (LDA) for feature space reduction and classification on the Palmer Penguins dataset.

It covers the complete data processing and classification lifecycle—from handling missing data and exploratory pairplots to evaluating classification performance using train-test split, accuracy scores, and confusion matrices. Additionally, LDA is utilized as a supervised dimensionality reduction technique to project 4D feature vectors into a 2D space that maximizes class separability while minimizing intra-class variance.
