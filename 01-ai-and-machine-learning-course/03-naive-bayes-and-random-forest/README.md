# Lung Cancer Prediction Using Naive Bayes and Random Forest

This project demonstrates a supervised machine learning workflow to predict lung cancer presence using health and lifestyle survey data.

It covers the complete data processing pipeline—including duplicate removal, categorical variable encoding via LabelEncoder, exploratory data analysis (EDA), correlation analysis, and handling class imbalance using ADASYN (Adaptive Synthetic Oversampling). Finally, Multinomial Naive Bayes and Random Forest classifiers are trained and evaluated using confusion matrices and classification reports.
