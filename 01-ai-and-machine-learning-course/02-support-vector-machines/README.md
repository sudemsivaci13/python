# Support Vector Machines (SVM)

This project demonstrates a supervised machine learning workflow using Support Vector Machines (SVM) to classify breast cancer tumors as either malignant or benign based on digitized features from fine needle aspirate (FNA) images.

It covers the complete binary classification lifecycle—from data exploration and class distribution visualization to feature scaling with StandardScaler and model training. The project also compares the performance of different kernel functions (Linear, RBF, and Polynomial) to demonstrate how non-linear decision boundaries handle complex biomedical datasets.
