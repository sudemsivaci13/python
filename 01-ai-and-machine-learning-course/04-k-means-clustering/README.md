# Unsupervised Clustering Analysis with K-Means

This project demonstrates an unsupervised machine learning workflow using the K-Means clustering algorithm on synthetic datasets of varying complexities.

It explores how K-Means groups unlabeled data by minimizing within-cluster variance. The analysis covers optimal cluster selection techniques using the Elbow Method and Silhouette Scores, as well as critical algorithm limitations such as sensitivity to feature scaling and poor performance on non-spherical cluster geometries.
