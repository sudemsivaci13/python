# Multi-Class Classification with Neural Networks

This application demonstrates a supervised machine learning workflow using Artificial Neural Networks (ANN) to classify three species of Palmer Penguins based on physical measurements and habitats. 

It covers the complete data lifecycle—from handling missing real-world data and categorical encoding to feature scaling and model training with Keras. Using a Softmax output layer, the model provides probability-based predictions, illustrating how neural networks handle multi-class decision-making processes.
